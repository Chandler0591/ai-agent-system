面向智能仓储的 AGV 调度仿真平台：10m×10m 物理仿真场景， 双引擎驱动（PyBullet / Gazebo + ROS 2），自然语言下达调度指令， 3D 实时呈现多车协同运行。

核心能力

从物理引擎到前端可视化的一体化闭环

⚙️

双后端物理仿真

PyBullet 轻量本地仿真与 Gazebo + ROS 2 物理驱动后端，共享同一套几何常量与 AGV URDF 模型，环境变量一键切换。

🧊

3D 实时可视化

Three.js 鸟瞰视图：货架/装卸区/AGV 三维建模，SSE 每 0.1s 推送位姿 + 前端插值平滑，所见即所仿。

🧠

自然语言调度

“把 agv_1 移到 B 区” —— LangGraph Agent 理解意图、调用仿真工具链，点击地图与对话双通道控制。

🚦

多车避障

静态货架防穿模校验（目标点 + 直线路径）+ 车-车动态避障：距离检测降速/等待、调度层错峰，多车同场无碰撞。

📋

任务优先级队列

TaskManager 支持优先级字段：高优先级插队、`get_next_pending` 按序出队，Celery 异步任务旁路。

📡

REST + SSE 开放接口

13 个 REST 端点 + SSE 位置推送，FastAPI 自动生成文档，任何前端/Agent 均可即插即用。

工作流程
